# Amazon Futures — Ecology & Elections

Interactive 20-year Amazon land-management teaching simulation for DEV1102. Students make a management decision every year, receive ecological/social consequences, and face elections every five years.

## Play online

Publish this repository using **Settings → Pages → Deploy from a branch → main → / (root)**. GitHub Pages will give a URL such as `https://YOUR-USERNAME.github.io/amazon-futures/`.

## Use

Open `index.html` in a browser or use the published GitHub Pages site. No backend required.

## Educational note

This is a simplified illustrative system-dynamics teaching model. Its numerical outcomes are not scientific forecasts or calibrated predictions for the Amazon.
